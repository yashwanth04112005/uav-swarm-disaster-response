## 2. Converting the Report into PDF (5 to 6 Pages)

You can convert [PROJECT_REPORT_DRAFT.md](file:///d:/IIITS/SEMESTER%207/Additional%20Project/uav_swarm_disaster_response/PROJECT_REPORT_DRAFT.md) into a PDF using any of these 3 methods:

### Option A: Google Docs / MS Word (Fastest)
1. Open Google Docs or Word.
2. Set Margins: Normal (1 inch / 2.54 cm), Page Size: A4, Font: Times New Roman or Calibri, 11 pt, 1.15 line spacing.
3. Copy-paste the content from `PROJECT_REPORT_DRAFT.md`.
4. Fill in your Name, Roll Number, and Mentor Name on the title page.
5. Insert 2 or 3 screenshots:
   - A screenshot of the 3D Isometric View running (`python main.py`).
   - A screenshot of the FLIR Thermal Mode (press `T`).
   - A screenshot of the Mission Debrief Scorecard (press `Tab`).
6. Export as PDF (`File > Download > PDF Document`). Check that page count is between 5 and 6 pages.

### Option B: Overleaf / LaTeX
If using Overleaf, paste the sections into standard IEEE conference or IIITS project template. The citations in Section 9 are already in standard IEEE format.

## 4. Google Drive Permission Verification (Crucial!)

To avoid the #1 fatal submission mistake ("Link cannot be opened"):
1. In Google Drive, right-click the video and report files $\to$ **Share**.
2. Under General Access, change "Restricted" $\to$ **"Anyone with the link can view"** (Viewer permission).
3. Copy the link.
4. Open a **New Incognito Window** (Ctrl + Shift + N in Chrome).
5. Paste the link into the address bar. If it loads without asking for a Google sign-in, it is 100% safe to submit!
